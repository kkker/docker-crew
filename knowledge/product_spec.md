# TitanCore Edge Gateway v2.5 技術規格書

## 1. 產品概述
本產品為工業級物聯網（IIoT）核心設備，主打邊緣 AI 算力與多重通訊協定轉換。

## 2. 硬體架構與運算核心
* **處理器**：工業級 4 核心 ARM Cortex-A72 (時脈 1.8 GHz)。
* **記憶體**：4GB LPDDR4X。
* **儲存空間**：內建 64GB eMMC 5.1 快閃記憶體。
* **硬體安全**：整合 TPM 2.0 安全晶片，支援 AES-256 資料加密。

## 3. 連接性與通訊協定
* **網路介面**：雙獨立 Gigabit Ethernet (RJ45) 埠。
* **序列埠**：2 埠 RS-232/422/485，完整支援 Modbus RTU 協定。
* **無線支援**：內建 Wi-Fi 5 與藍牙 5.0，具備 5G/LTE 擴充彈性。

## 4. 環境與物理規格
* **耐受溫度**：支持 -40°C 至 75°C 寬溫無風扇運作。
* **防護等級**：高強度鋁合金機殼，具備 IP40 防塵等級。
* **安裝方式**：支援 DIN-Rail 導軌安裝。


### IP 等級數字的意義
* **第一個數字（防塵，0–6）**：數字越大，防止灰塵與異物進入的能力越強。例如 6 代表完全防塵，灰塵無法進入。
* **第二個數字（防水，0–9K）**：數字越大，抵抗水分滲透的能力越強。例如 [IP67防水等級](https://www.openworld.tv/blog/ip67-waterproof-rating-guide.html) 中的 7 代表可短暫浸泡水中。

#### 常見等級與應用情境
* **IP44**：防止潑水與大於 1mm 的固體；適合室內潮濕空間或一般浴室燈具。
* **IP65**：完全防塵，並可抵抗低壓水柱噴射；適合戶外壁燈或雨遮下的插座。
* **IP67**：完全防塵，可在水深 1 公尺內浸泡 30 分鐘；適合戶外地燈或可能積水的位置。
* **IP68**：完全防塵，可長時間在指定深水（超過 1 公尺）中浸泡；適合水池燈具或水下設備。
* **IP69 / IP69K**：完全防塵，並可承受高溫、高壓水柱清洗；適合醫療或極端潔淨與工業環境。

## 5. 軟體架構
* **作業系統**：內建基於 Linux 5.15 的 TitanOS。
* **容器支援**：原生整合 Docker / K3s 容器架構。
* **數據轉換**：內建 Protocol Broker，可自動將 Modbus/OPC UA 數據流轉換為 MQTT/HTTPS 上傳公有雲。
